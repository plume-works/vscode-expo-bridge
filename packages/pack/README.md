# Expo Bridge

Build, install, launch, and screenshot an Expo iOS app on the Mac host from a devcontainer
opened by VS Code on a Mac, with EAS cloud as the fallback. This pack installs the host
extension (in the Mac's local extension host) and the workspace extension (in the
container).

See the [protocol and security model](https://github.com/plume-works/vscode-expo-bridge).
